Card images go here, named by archetype number, zero-padded, as PNG:

  01.png  02.png  03.png ... 64.png

The page requests /cards/NN.png for the user's Sun archetype. If a file is
missing, a styled fallback tile is shown instead - so it is safe to launch
with an incomplete deck.
